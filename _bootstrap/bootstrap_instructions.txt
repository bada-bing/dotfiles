# Instructions for bootstrapping your new macOS machine.
#
# 1. Make sure the machine has a folder in the dotfiles, named after its hostname (e.g. mini/).
#    For a new machine, copy the closest folder, trim it, and push it first.
# 2. Log in to your Apple ID to enable iCloud Drive.
# 3. Wait for iCloud Drive to sync this file.
# 4. Execute the 'Bootstrap Command', and follow the prompts in the Terminal.
#    At the hostname step, choose the machine's folder.

# --- Bootstrap Command ---
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/bada-bing/dotfiles/main/_bootstrap/setup_machine.sh)"

# --- Repeating steps later ---
~/Developer/toolbox/dotfiles/_bootstrap/setup_machine.sh --list
